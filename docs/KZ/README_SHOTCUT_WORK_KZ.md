# Shotcut арқылы MediaPanel-де бейнемонтаж

## Оңтайлы жұмыс барысы келесідей:

### Shotcut бағдарламасын ашу
`MediaPanel UI` мәзіріне өтіңіз: **4) Production -> 8) Launch Shotcut** және бастапқы бейнеүзінділеріңізді (клиптерді) тексеріңіз.
*   Жұмыс процесінде Shotcut жоба файлы (.mlt) автоматты түрде жасалып қойған.

### Алғашқы монтаж (rough cut) жасау
Уақыт шкаласында (Timeline):
```text
таңдау → кесу → көріністерді реттеу → түпкілікті ұзақтық
```

*   Алдымен, фильмде нақты не қалатынын шешіп алыңыз.

### Shotcut-та жылдам кесу
1.  Ойнату меңзерін (playhead) қажетті орынға қойыңыз.
2.  Клипті меңзер тұрған жерден кесу үшін **S** пернесін (Split at Playhead) қолданыңыз.
3.  Қарауды жалғастырып, келесі кесу әрекеттерін жасаңыз.
4.  Қажетсіз бөліктерді таңдап, өшіріңіз.
5.  Қалған бөліктердің орнын ауыстыруға және реттеуге болады.
Бұл өте жылдам жұмыс циклін қалыптастырады:
```text
Қарау → S → Қарау → S → Қарау → S
↓
Қажетсіз бөліктерді өшіру
```

### Қарау барысында жылдам кесуге арналған пайдалы Shotcut пернелері
Мысалы, қарау кезінде:
```bash
▶ Бейне
↓
Space (Бос орын) — Тоқтату
↓
← / → — Нақты жерді табу
↓
S — Кесу
↓
Қарауды жалғастыру
↓
S — Екінші рет кесу
↓
Сәтсіз бөлікті таңдау
↓
X — Өшіру (уақыт шкаласындағы элементтердің ығысуымен)
↓
Ctrl+Z — Қате кесу немесе өшіру әрекетін болдырмау (қайтару)
↓
```

### Тінтуірді үнемі қолданбай өте жылдам монтаждау
J-K-L — кәсіби монтажшы сияқты бейнематериалды қарап шығуға мүмкіндік беретін өте пайдалы пернелер тобы:
J  ← Артқа айналдыру
K  ■ Тоқтату
L  → Алға айналдыру / Ойнату

### Белгілі бір клипті тұрақтандыру
**Тұрақтандыру** (Stabilize сүзгісі) — тек шынымен қажет болған жағдайда ғана клиптер немесе бөліктер үшін қолданыңыз. Тұрақтандыру кадр геометриясын өзгертеді: ол дірілді өтейді, бұл кескінді үлкейтуді және шеттерін қиып тастауды қажет етуі мүмкін.
Мұны **кескінді түпкілікті өңдеуден бұрын** жасаған дұрыс. * Егер белгілі бір сегменттерді тұрақтандырғыңыз келсе, оларды кескеннен кейін қайта біріктірмеңіз.

### Тұрақтандыру кезінде кадрдың 50–90°-қа кенеттен секіруі орын алса
Бұл айналуды өтеу кезіндегі қателікке немесе дірілді түзетудің стандартты әдістері үшін тым үлкен айналу бұрышына ұқсайды.
Алдымен мыналарды тексеріңіз:
1. "Stabilization" (Тұрақтандыру) функциясын өшіріп, сол бөлікті ойнатып көріңіз.
2. Егер секіру жоғалса, сүзгіні қайта қосып, "Analyze" (Талдау) әрекетін қайта орындаңыз және нәтижені сол клипке арналған жаңа .stab файлына сақтаңыз. Басқа көрініске (сценаға) арналған талдау файлын таңдамаңыз.
3. Тапсырманың аяқталуын күтіп, сол сәтті қайта тексеріңіз.
Егер секіру дәл сол жерде қайталанса, бастапқы бейнематериалды қарап шығыңыз: кенеттен болған сілкіністі, бұлыңғыр кадрды немесе фонды жауып тұрған адамды іздеңіз. Қате айналуды кері айналу арқылы түзетуге тырысқаннан гөрі, мұндай қысқа сегментті тұрақтандырмай қалдырған дұрыс.

### Бүкіл Timeline (Уақыт шкаласы) жолына арналған сүзгілер
1. **Шуды азайту** (Wavelet Denoise сүзгісі) / **кескінді тазарту**.
Тұрақтандырудан кейін кадрдың түпкілікті геометриясы қалыптасады, содан кейін цифрлық шуды жоюға болады.
Мысалы:
```text
Stabilize (Тұрақтандыру)
↓
Vaguedenoiser (Шуды басу)
```

* Шуды қатты басу әдісін абайлап қолданыңыз: ол ұсақ бөлшектерді жойып жіберуі мүмкін.
* Егер алдымен шу жойылмаса, Sharpen (Айқындықты арттыру) сүзгісі оны күшейтіп жіберуі мүмкін.
2. **Түсті түзету** (White Balance, Contrast және Color Grading сүзгілері)
Кескін тазартылғаннан кейін мына параметрлерді реттеу ыңғайлы:
- экспозиция;
- контраст;
- ақ түс балансы;
- қанықтылық;
* Егер "Colgate" деп сіз қолданып жатқан түсті түзету сүзгісін айтып тұрсаңыз, мен оны Contrast (Контраст) сүзгісінен кейін орналастырар едім.
3. **Айқындық** (Sharpen сүзгісі) — қажет болған жағдайда.
* Айқындықты арттыруды шуды басу және түсті түзету әрекеттерінен кейін қолданған дұрыс.
* Егер алдымен айқындықты арттырып, содан кейін шуды бассаңыз, қосылған айқындықтың бір бөлігі сөзсіз жоғалады. ### Өтулерді (transitions) тексеру
Shotcut бағдарламасында өтулерді жасаудың стандартты тәсілі — бір жолдағы клиптерді бір-бірінің үстіне қабаттастыру.
1. V1 жолына екі клипті қатар қойыңыз.
2. Екінші клипті бірінші клиптің соңымен қабаттасатындай етіп, сәл солға қарай жылжытыңыз.
3. Қабаттасқан аймақта күлгін түсті өту блогы пайда болады.
4. Осы блокты таңдаңыз.
5. «Сипаттар» (Properties) панелін ашыңыз.
6. «Бейне» (Video) өрісінде өту түрін таңдаңыз:
- Dissolve (Еріту) — стандартты айқаспалы еріту; - Bar (Жолақ), Iris (Ирис), Clock (Сағат), Diagonal (Диагональ) және басқа пішінге негізделген өтулер.
7. Күлгін блоктың шеттерін жылжыту арқылы ұзақтығын реттеңіз.

## Shotcut-та сүзгілер жиынтығының алдын ала орнатылымын (preset) қалай орнатуға болады

### MediaPanel ішінде
1. `MediaPanel UI` мәзірін пайдаланыңыз:
```text
1) System status -> 5) Import Shotcut filter sets
```

2. `Shotcut` бағдарламасында мынаны ашыңыз:
```text
Filters → + → Sets
```

Онда жазба пайда болуы керек, мысалы:
```bash
Oppo_Reno_11F_Concert
```

3. Сүзгілер жиынтығын бүкіл жолға қолданыңыз.

### Shotcut бағдарламасында
Сіз `Shotcut Flatpak` нұсқасын пайдаланып жатқандықтан, файл жолын қолмен болжап іздемеген жөн.

1. `Shotcut` бағдарламасын ашыңыз.
2. Мынаны таңдаңыз:
```text
Settings → App Data Directory → Show
```

3. Мына буманы (каталогты) табыңыз:
```bash
filter-sets
```

* Егер бұл бума жоқ болса, дәл осы атаумен жаңасын жасаңыз.

4. Ол жерге файлды көшіріңіз, мысалы:
```bash
Oppo_Reno_11F_Concert
```

5. `Shotcut` бағдарламасын толығымен жабыңыз.
6. `Shotcut` бағдарламасын қайта іске қосыңыз.
7. Мынаны ашыңыз:
```text
Filters → + → Sets
```
Сол жерде `Oppo_Reno_11F_Concert` пайда болуы тиіс.

## Алдын ала орнатылған параметрлерді (пресеттерді) дәл баптау

Пресеттер жинағы бейнені өңдеу кезінде өте ыңғайлы. Дегенмен, бейнедегі жекелеген клиптер **дәл баптауды** қажет етуі мүмкін.
Дәл баптау кезінде сүзгі параметрін бір немесе екі қадамға өзгертіп, нәтижені алдын ала қарап шығасыз.
1. Ойнатқыштың жоба қойындысында **Toggle Zoom** (Масштабты ауыстыру) опциясын таңдап, сүзгі параметрінің өзгеру әсерін үлкейтілген масштабта қараңыз.
2. Бейнедегі өзгерістердің нәтижесін көру үшін **Player > External Monitor > Preview Window (HDR)** тармағын таңдаңыз (немесе **Ctrl+`** пернелерін басыңыз).

## MediaPanel-де өңдеу кезінде жаңалықтар мен спорттық түсірілімдердегі ақауларды түзету

### Ақаулы аймақты қосымша кадрмен (cutaway shot) жабу
Дыбыс үзілмей жалғаса береді, ал сапасыз кадр басқа бейне кадрмен алмастырылады. 1. `001_Video_final.mp4` файлын қайта өңдемеңіз; қайта кодтау сапаны аздап төмендетеді. Бастапқы .mlt жобасының көшірмесін жасаңыз:
```bash
001_Video (Copy).mlt
```
2. Shotcut бағдарламасын ашып, жөндеу процесі үшін .mlt файлының көшірмесін сақтаңыз (мысалы, «Save As» — «Басқаша сақтау» функциясын қолданып):
```bash
001_Video_repair.mlt
```

3. «Detach Audio» (Дыбысты бөлу) командасын қолданып, ақауы бар клиптен дыбысты бөліп алыңыз және оны A1 дыбыс жолында тұтас күйінде қалдырыңыз. Shotcut бағдарламасы дыбысты клиптің контекстік мәзірі арқылы бөлуге мүмкіндік береді.
4. Дыбыстың кездейсоқ жылжып кетуіне жол бермеу үшін A1 жолын құлыптаңыз.
5. Бейне жолында келесідей кесулер жасаңыз:
- ақау пайда болғанға дейін бірнеше кадр бұрын;
- ол жоғалғаннан кейін бірден.
6. «Lift» (Алып тастау) функциясын қолданып, тек ақауы бар бейне бөлігін жойыңыз және клипте бос орын қалдырыңыз. «Ripple Delete» (Ығыстыра отырып жою) функциясын қолданбаңыз, әйтпесе оң жақтағы барлық элементтер дыбыспен сәйкес келмей қалады (синхронизация бұзылады).
7. Пайда болған бос орынның дәл үстіндегі V2 жолына қосымша кадрды (cutaway) орналастырыңыз.
8. .mlt файлын түпкілікті экспорттауға арналған негізгі нұсқа ретінде сақтаңыз:
```bash
001_Video.mlt
```

* Нәтижесінде сізде үш .mlt файлы болады: біреуі экспорттауға арналған негізгі нұсқа, ал екеуі болашақтағы ықтимал өзгертулерге арналған.
Ақаулы бөліктің алдындағы бір секундтық кадрды емес, қойылымның басқа жеріндегі ұқсас «таза» фрагментті пайдаланған дұрыс:
- сахнаның жалпы көрінісі;
- музыкант немесе барабаншы;
- жарықтың қозғалысы;
- орындаушының қолдары немесе аспабы;
- көрермендердің реакциясы.
Немесе жобаның `scenes/` каталогындағы, өңдеу процесі (pipeline) арқылы жасалған клипті пайдалануға болады.
Егер ақаулы жерге іргелес кадрларды қайталасаңыз, көрермен «артқа секіру» (jump back) әсерін байқауы мүмкін. Егер басқа кадр болмаса, қайталауды масштабты аздап үлкейту (103–105%-ға дейін) арқылы жасыруға болады. ### Баяулату
Бір секундтық үзінді үшін шамамен 0,7–0,85 секундтық бастапқы бейнематериалды алып, жылдамдықты мына мәнге орнатыңыз:
```bash
0,70–0,85×
```

Формула:
```text
Жылдамдық = бастапқы қосымша кадрдың ұзақтығы / үзінді ұзақтығы
```

Мысал:
```text
0,75 секунд / 1,00 секунд = 0,75× жылдамдық
```

* Егер бастапқы бейнематериал 60 кадр/с (fps) жылдамдықпен түсіріліп, жоба шамамен 30 кадр/с жылдамдықта болса, 0,5× жылдамдықты пайдалануға болады — қозғалыс бірқалыпты болып қалады. Ал 30 кадр/с жылдамдықпен түсірілген материал үшін жылдамдықты 0,75–0,8× деңгейінен төмендетпеген жөн, әйтпесе бейне үзік-үзік болып көрінуі мүмкін.

Кадрдың басталу және аяқталу тұстары үшін мына тәсілдерді қолданып көріңіз:
- музыка ырғағына дәл сәйкес келетін тікелей ауысу (hard cut) — бұл көбінесе ең тиімді шешім болып табылады;
- немесе кадрлар бір-бірінен айтарлықтай өзгеше болған жағдайда, өте қысқа (3–5 кадрлық) біртіндеп ауысу (dissolve) әдісін қолдану.

[!] Маңызды сәт: дыбысты қимаңыз және баяулатпаңыз. Бұл музыка мен фестиваль атмосферасының табиғи күйін сақтауға, сондай-ақ бір секундтық қосымша кадрдың режиссерлік ойластырылған шешім ретінде қабылдануына мүмкіндік береді. ## Соңғы MP4 файлына экспорттау

MediaPanel-де белсенді жобаны соңғы "001_Video_final.mp4" файлына экспорттау үшін келесі мәзір қолданылады:
```text
5) Export -> 1) Render Export (бейнелерді жасау)
```

## Қысқа бейнеролик жасау

1. `MediaPanel UI` арқылы `Shotcut` бағдарламасын ашыңыз:
```text
6) Tools -> 1) Video tools -> 1) Shotcut
```

2. `Жаңа жоба` (New Project) жасаңыз:
Жоба қалтасы: 001_Текущий_проект
Жоба атауы: short
Бейне режимі: таңдалған көріністің кадр жиілігіне сәйкес келетін 4K UHD 2160p
Басыңыз: Start (Бастау)
3. `scenes/` каталогынан файлды таңдаңыз:
```text
File -> Open File
```

4. Файлды уақыт шкаласына (Timeline) сүйреп апарыңыз.
5. Қажет болса, 3 және 4-қадамдарды қайталаңыз.
6. Клипті өңдеу бойынша қажетті әрекеттерді орындаңыз: қию, тұрақтандыру (қажет болса), түс түзету, субтитрлер қосу.
7. `Shotcut` бағдарламасында `Timeline` -> `Output` элементі үшін көлденең бейнені тік форматқа түрлендіруге болады:
