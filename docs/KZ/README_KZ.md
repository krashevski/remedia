# REMEDIA

[🇬🇧 Ағылшын тілі](../../README.md) | [🇷🇺 Орыс тілі](../RU/README_RU.md) | [🇰🇿 Қазақ тілі](README_KZ.md)

**Remedia** — Debian/Ubuntu жүйелеріне арналған, мына бағыттарға шоғырланған модульдік жүйелік орта:
* медиа өндірісі
* жүйені қалпына келтіру
* тұтастықты бақылау
* қауіпсіз пакеттерді басқару
Remedia CLI (пәрмен жолы интерфейсі) фреймворкін, орындалу ортасын (runtime), тізілімді және модульдік архитектураны біртұтас инженерлік жүйеге біріктіреді.

## ✨ Негізгі идеялар

Remedia абстрактілі құрал ретінде емес, Linux жүйелеріндегі нақты мәселелерге жауап ретінде жасалған:
* рұқсаттар мен иелік құқықтарының бұзылуы
* бақылаусыз орнатудан кейінгі скрипттер (postinstall scripts)
* пакеттерді жойғаннан кейін жүйенің ластануы
* орнату алдында қауіпсіз аралық кезеңнің (staging) болмауы
* жұмыс ортасын қалпына келтірудің қиындығы

Жоба мына бағыттарда дамуда:
* **транзакциялық жүйелік әрекет**
* **манифест арқылы басқарылатын күй**
* **қалпына келтіруге басымдық беретін архитектура**
* **орындалу ортасын оқшаулау**
* **модульдік CLI оркестрлеуі**

## 🧱 Архитектура

Remedia — жай ғана скрипттер жиынтығы емес. Бұл көп деңгейлі жүйе:
```text
remedia
├── CLI (кіру нүктесінің маршрутизаторы)
├── Runtime (орындау ортасы)
├── Registry (модульдер + келісімшарттар)
├── Modules
│ ├── system
│ ├── mediasystem
│ ├── mediapanel
│ ├── backupkit
│ └── demo
└── Config (/etc/remedia)
```

## Орнату алдында

Remedia жұмыс деректерін (жоғары жылдамдықты қажет ететін), бастапқы медиа файлдарды және сақтық көшірмелерді әртүрлі дискілерге бөліп орналастыруға арналған.
Remedia-ны орнатпас бұрын қажетті диск бөлімдерін немесе (ең аз талап етілетін орнату үшін) каталогтар мен бекіту нүктелерін (mount points) жасап, бекітіңіз.

### Ұсынылатын орналасу:

| Бекіту нүктесі      | Мақсаты                           | Ұсынылатын диск          |
|--------------------|-----------------------------------|--------------------------|
| /mnt/shotcut       | Прокси-файлдар мен уақытша жобалар | Жылдам SSD               |
| /mnt/storage       | Бастапқы медиа файлдар мен жобалар | Сыйымдылығы үлкен HDD немесе SSD |
| /mnt/backups       | Архивтер мен сақтық көшірмелер    | Бөлек HDD                |

### Ең аз талап етілетін орналасу:

Пайдаланушы алдын ала тиісті каталогтарды немесе бекіту нүктелерін жасаған жағдайда, Remedia бір дискіде де жұмыс істей алады. Дегенмен, бұл конфигурацияда өнімділік пен сақтық көшірме сенімділігі төменірек болады.

```bash
sudo apt install remedia_1.3.0_all.deb
```

* coreutils

## 🖥 Пайдалану

### CLI
```bash
remedia
```

### UI іске қосу
```bash
remedia system center
```

### Remedia іске қосылғаннан кейін

REMEDIA SYSTEM CENTER ішінде `3) System` мәзірін ашып, мынаны іске қосыңыз:
```text
3) Create symlinks for user big directories
```

Бұл функция пайдаланушының үй каталогында бекітілген дискілерде орналасқан Remedia деректер каталогтарына сілтеме жасайтын символдық сілтемелерді автоматты түрде жасайды.

## 🧩 Негізгі компоненттер

### MediaSystem
Медиа өндірісіне арналған конвейерлік (pipeline) жүйе.

### MediaPanel
Медиа ортасын басқару және жұмыс процесіне арналған интерфейс. ### BackupKit (Reincarnation)
Пайдаланушы деректері мен жүйе күйін қалпына келтіруге арналған жүйе.

### Жүйелік құралдар
Диагностика, мониторинг және қызмет көрсету құралдарының жиынтығы.

## 🧠 Манифест моделі

Remedia **манифестке негізделген жүйе күйінің моделін** ұсынады.
Манифест:
* күтілетін күйді сипаттайды
* **сенім тірегі** (trust anchor) ретінде қызмет етеді
* жүйе жұмысының нашарлауынан кейін оны қалпына келтіруге көмектеседі

## 🔍 Remedia Doctor (жоспарланған)



## 🔐 Философия

Remedia — пакет пен жүйе арасындағы қосымша қабат.
Ол мынадай мүмкіндіктерді қосады:
* орнату алдындағы тексеру
* файлдық жүйені бақылау
* орындау процесін оқшаулау
* қолданысқа енгізу алдында пакеттерді талдау мүмкіндігі
Бұл жүйені мыналарға жақындатады:
* «құмсалғыш» (sandbox) режимінде тексеру
* орналастыруды имитациялау
* қайта жасауға болатын (reproducible) орталар

## 🎬 Жобаның басталу тарихы

Жоба мыналардың негізінде қалыптасты:
* бейне өңдеу жұмыстары (Shotcut)
* тұрақты ортаға деген қажеттілік
* жүйені қайта-қайта қалпына келтіру қажеттілігі
* Linux-пен жұмыс істеу барысында жинақталған тәжірибе

Алдымен **Reincarnation Backup Kit** пайда болды,
содан кейін одан **Media System** бөлініп шықты,
ал соңында **Remedia** толыққанды жүйе ретінде қалыптасты.

## 📎 Қорытынды

Remedia — Linux ортасын мынадай сипаттарға ие етуге бағытталған талпыныс:
* Төзімділік
* Болжамдылық
* Қалпына келтірілу мүмкіндігі
* Ұзақ мерзімді жұмысқа жарамдылық

Жай ғана «жұмыс істейтін» емес, сонымен қатар **тұрақты әрі уақыт сынына төтеп бере алатын** жүйе.
