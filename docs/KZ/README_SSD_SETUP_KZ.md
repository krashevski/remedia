# Linux үшін SSD + HDD бөлімдері (Shotcut бағдарламасында өңдеу үшін оңтайландырылған)

[🇬🇧 English](../EN/README_SSD_SETUP_EN.md) | [🇷🇺 Русский](../RU/README_SSD_SETUP_RU.md) | [🇰🇿 Қазақ тілі](README_SSD_SETUP_KZ.md)

Shotcut бағдарламасында өңдеуге арналған SSD + HDD бөлімдері және конфигурациясы

## 📌 Жалпы идея

- **480 ГБ SSD** жүйе, бағдарламалар, пайдаланушы деректері және бейнені өңдеу кэші үшін қолданылады.
- **Қатты диск (1–2 ТБ немесе одан көп)** бастапқы файлдар мен аяқталған жобаларды сақтау үшін қолданылады.
- Өңдеуді жеделдету және /home қалтасын таза ұстау үшін **Shotcut кэші** үшін SSD-де бөлек бөлім бөлінген.

## 📊 480 ГБ SSD үшін ұсынылған бөлімдер

| Бөлім / Орнату нүктесі      | Өлшемі   | FS    | Мақсаты                                                                  |
|-----------------------------|----------|-------|--------------------------------------------------------------------------|
| `/boot/efi`                 | 512 МБ   | FAT32 | EFI - жүктеу (егер UEFI пайдаланылса).                                   |
| `/` (root)                  | 50 ГБ    | ext4  | Жүйе және бағдарламалар.                                                 |
| `swap`                      | 8 ГБ     | swap  | 16 ГБ жедел жады жеткілікті. Ұйқылық күй үшін make = RAM мәнін таңдаңыз. |
| `/home`                     | 180 ГБ   | ext4  | Пайдаланушының үй каталогтары, параметрлер, құжаттар, шағын деректер.    |
| `/mnt/shotcut`              | 240 ГБ   | ext4  | Shotcut үшін жұмыс қалтасы (кэштер, проксилер, уақытша рендерлер).       |
| **Барлығы**                 | ~478 ГБ  |       | SSD қызмет көрсету блоктары үшін аз ғана резерв қалды.                   |

> [!] Маңызды: Егер сіз Ubuntu-ны UEFI+GPT аналық плата режимінде орнатып жатсаңыз, сізге арнайы ESP (EFI жүйелік бөлімі) бөлімі қажет болады, оны орнатушыда дұрыс белгілеуіңіз керек.
Ubuntu орнатқан кезде:
1. SSD дискісінде (мысалы, /dev/sdc1), Use as ашылмалы тізімінен EFI жүйелік бөлімін (немесе "Жүктелетін EFI") таңдаңыз.

2. Төменгі жағында, Bootloader орнату құрылғысы өрісінде бөлімді емес, бүкіл SSD дискісін (/dev/sdc) көрсетіңіз.
Орнатудан кейінгі тексеру:
> [!] BIOS/UEFI+GPT жүйесінде жүктеу ретін SSD (sdc) бірінші болатындай етіп конфигурациялаңыз.
> [!] UEFI+GPT режимі үшін BIOS/UEFI жүйесінде Legacy+MBR режимін қолдауды өшіріңіз.

## 📂 HDD (мысалы, 1–2 ТБ)

| Орнату нүктесі                        | Мақсатты орын                                 |
|---------------------------------------|-----------------------------------------------|
| `/mnt/storage` (үшінші қатты дискіде) | Егер екінші пайдаланушы болса.                |
| `/mnt/backups` (екінші қатты дискіде) | Ескі жобалардың мұрағаты, сақтық көшірмелері. |

> [!] Сыртқы USB қатты дискісі баяу жұмыс істеуіне байланысты пайдаланушы деректерінің сақтық көшірмесін жасауға жарамсыз.

## ✅ Бұл орнатудың артықшылықтары

1. Жүйе мен бағдарламалар жылдам (`/` бөлімі бөлек).
2. Shotcut кэші `/home`-ді бітемейді және тазалау оңай.
3. Қатты диск SSD жүктемей, тек үлкен файлдарды сақтау үшін қолданылады.
4. Бірнеше ірі жобаларды бір уақытта іске қосуға болады.
5. "Орнатыңыз және ұмытыңыз" тепе-теңдігі — кеңістік үшін үнемі күрес жоқ.

## 🔑 Ыңғайлы жұмыс істеу үшін SSD-нің минималды өлшемдері

- **80–100 ГБ** — бастапқы минимум (барлық ауыр файлдарды қатты дискіге жылжытуда өте тәртіпті болу керек).
- **120–128 ГБ** — жүйе үшін ыңғайлы + /home (бірақ кэшті HDD-де сақтау керек).
- **240–256 ГБ** — Shotcut кэшіне орын бөлуге болады, бірақ ол шектеулі.
- **480 ГБ** — оңтайлы тепе-теңдік: жүйе, пайдаланушылар және SSD-дегі өңдеу, HDD-дегі деректер.
