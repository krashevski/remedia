# NVIDIA Flatpak NVENC Doctor / Heal

Модуль реализует сценарий `nvidia-flatpak-nvenc(8)` для Shotcut Flatpak.
В MediaPanel System Status добавлены пункты **6) Shotcut Flatpak NVENC doctor** и **7) Shotcut Flatpak NVENC heal**.

```bash
remedia system nvidia-flatpak-nvenc doctor
remedia system nvidia-flatpak-nvenc heal
```

Запускайте от пользователя рабочего стола, без sudo. Doctor не устанавливает
пакеты, не меняет overrides и не загружает модули NVIDIA. Он запускает небольшой
тест ffmpeg внутри установленного Shotcut; Flatpak может создавать обычные
временные данные и кеши, но выходное видео не сохраняется.
При отсутствии загруженного NVIDIA-модуля nvidia-smi не вызывается:
сначала нужно проверить хост через `remedia system nvidia-display doctor`.

Doctor проверяет:

- работающий драйвер хоста и полную версию из nvidia-smi;
- активные GL-драйверы Flatpak;
- единственную установку и ветку Shotcut, архитектуру и runtime;
- точное расширение `org.freedesktop.Platform.GL.nvidia-<полная-версия>//1.4`
  в выбранной установке и наличие того же ref в других установках;
- реальное кодирование 30 кадров 640x360 при 30 fps через h264_nvenc;
- при отсутствии расширения и неудачном тесте — наличие точного ref в выбранном remote.

Видео теста длится одну секунду. Выполнение ограничено тайм-аутом 45 секунд
плюс до 5 секунд на завершение зависшего процесса. Успех требует кода 0,
30 кадров и `progress=end`, а не только наличия h264_nvenc в списке кодеков.
Успешный тест не гарантирует успешный рендер любого проекта MLT или фильтра.

Если Shotcut найден в нескольких установках или ветках, автоматический выбор
не производится. Можно выбрать явно:

```bash
remedia system nvidia-flatpak-nvenc doctor --scope=system
remedia system nvidia-flatpak-nvenc doctor --scope=user
remedia system nvidia-flatpak-nvenc doctor --scope=media --branch=stable
remedia system nvidia-flatpak-nvenc heal --scope=system --remote=flathub
```

Именованные установки поддерживаются через штатный `--installation=NAME`.
По умолчанию remote — `flathub`; другое настроенное имя задаётся `--remote=...`.
Новые remote не добавляются. Запрос remote-info ограничен 20 секундами
плюс до 3 секунд на завершение процесса.

Heal сначала выполняет Doctor. Установка возможна только если тест не прошёл,
точное расширение отсутствует в выбранной установке Shotcut, требуемый GL-драйвер
активен и точный ref с архитектурой Shotcut подтверждён через remote-info.
После вывода scope, remote и ref пользователь вводит полный короткий ref.
EOF или другое значение отменяют действие. Перед установкой повторно проверяются
версия драйвера, выбранная установка Shotcut и доступность расширения.

Flatpak install вызывается с `--no-related --no-deps` и сохраняет собственный
запрос подтверждения. Для системной установки разрешение запрашивается самим
Flatpak/Polkit; Remedia не перезапускается через sudo. Драйвер хоста, overrides,
старые расширения и остальные приложения не меняются.

Heal затем повторяет Doctor и реальный encode в той же выбранной установке.
Если расширение уже присутствует, но тест не проходит, модуль выдаёт ошибку
без слепой переустановки. При неудаче предлагается CPU-экспорт `libx264`;
настройки MediaPanel автоматически не переключаются.

Общий System Doctor не запускает этот аудит или encode. В MediaPanel тест запускается только отдельным выбором Doctor/Heal; Refresh показывает последний результат.
При запуске диагностики из-под root модуль попросит повторить её от пользователя
рабочего стола, чтобы не исследовать Flatpak-профиль root вместо нужного пользователя.

Коды: 0 — тест успешен; 10 — инструменты/контекст недоступны; 11 — драйвер хоста
не готов; 12 — версия драйвера не определена однозначно; 13 — Shotcut не найден;
14 — несколько установок/веток; 20 — доступен подтверждаемый план установки;
21 — remote отсутствует; 22 — точный ref не подтверждён; 23 — расширение есть,
но тест не прошёл; 24 — нужный GL-драйвер не активен. Ошибки flatpak install
сохраняют собственный код. Отмена возвращает 1, неверные опции — 2.

Тесты с подставными командами, без настоящей установки Flatpak и кодирования GPU:

```bash
python3 tests/test_nvidia_flatpak_nvenc.py
```

Реализован модуль Doctor/Heal. Восстановление на настоящем оборудовании пока
не проверено; проверка исправной системы не подтверждает ветку восстановления.
