## Backup Kit User home

**Remedia Backup Kit (REBK)** — система резервного копирования и восстановления пользовательских данных Linux, ориентированная на быстрое инкрементальное архивирование, проверяемую историю резервных копий и предсказуемое восстановление.
Вместо создания полного архива домашнего каталога при каждом запуске Backup Kit использует **разностное инкрементальное TAR-архивирование**.
Каждый новый архив содержит только изменения относительно своего родительского архива. Связи между полными и разностными резервными копиями образуют **граф зависимостей**, благодаря которому система знает, от какого состояния происходит каждый последующий архив.
Это позволяет значительно уменьшить объём повторно сохраняемых данных и ускорить регулярное резервное копирование.
Периодически создаётся новый **полный снимок пользовательского каталога с помощью `rsync`**. Он становится новой базовой точкой для последующей цепочки быстрых разностных архивов.
Таким образом, Backup Kit сочетает два подхода:
- периодические полные резервные копии;
- быстрые инкрементальные TAR-архивы между ними.

### Контроль целостности

Проверка резервных копий встроена непосредственно в процесс архивирования.
Встроенный **Doctor** анализирует граф архивов и проверяет состояние родительских резервных копий. Если родительский архив отсутствует, повреждён или цепочка зависимостей нарушена, система сообщает об этом и не рассматривает такую ветвь как полностью здоровую.
Благодаря этому пользователь получает не просто набор архивных файлов, а контролируемую и проверяемую историю резервных копий.

### Восстановление User Home

Backup Kit поддерживает восстановление пользовательского домашнего каталога.
При восстановлении система использует структуру резервных копий и последовательно воспроизводит необходимую цепочку от полного архива до выбранного инкрементального состояния.
Это позволяет восстановить User Home не только из последнего полного снимка, но и из состояния, сформированного последующими разностными архивами.

### Основная идея

Remedia Backup Kit строится по принципу:
**Full backup → Differential archives → Graph validation → Restore**
Полные снимки обеспечивают надёжную базовую точку, быстрые разностные TAR-архивы сохраняют изменения, граф описывает отношения между архивами, а встроенный Doctor постоянно контролирует пригодность цепочки для восстановления.
В результате резервное копирование остаётся быстрым для повседневного использования, но при этом сохраняет проверяемую структуру, необходимую для надёжного восстановления пользовательской среды.

## Firefox Backup

Remedia Backup Kit также имеет отдельные средства резервного копирования Firefox.
Они позволяют:
- архивировать профиль Firefox;
- создавать переносимый HTML-файл закладок Firefox;
- восстанавливать сохранённый профиль;
- сохранять закладки независимо от полного архива User Home.
Это особенно полезно после переустановки Linux или восстановления пользовательского окружения на новой системе.
