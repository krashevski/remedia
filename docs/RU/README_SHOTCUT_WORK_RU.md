# Редактирование видео в MediaPanel через Shotcut

## Оптимальный порядок такой:

### Откройте Shotcut 
В меню `MediaPanel UI` 4) Production -> 8) Launch Shotcut и проверьте исходные клипы.
* Shotcut project file (.mlt) уже создан в pipeline 

### Сделайте монтажную нарезку
На Timeline:
```text
отбор → нарезка → порядок сцен → окончательная длительность
```

* Сначала вы решаете, что вообще останется в фильме.

### Быстрая нарезка в Shotcut
1. Поставьте курсор воспроизведения в нужное место.
2. Используйте S — Split at Playhead — разрезать клип в позиции курсора.
3. Продолжайте просмотр и ставьте следующие разрезы.
4. Ненужный фрагмент выделяете и удаляете.
5. Оставшиеся фрагменты можно двигать и менять местами.
Получается очень быстрый цикл:
```text
Просмотр → S → просмотр → S → просмотр → S
                         ↓
    удалить ненужное
```

### Полезные клавиши Shotcut для быстрой нарезки во время просмотра
Например, вы смотрите:
```bash
▶ видео
    ↓
Space — остановили
    ↓
← / → — точно нашли место
    ↓
S — разрезали
    ↓
продолжили просмотр
    ↓
S — второй разрез
    ↓
выделили плохой кусок
    ↓
X — удалили его вместе со сдвигом Timeline
    ↓
Ctrl+Z - отменить ошибочный разрез/удаление
```

### Очень быстрый монтаж без постоянного обращения к мыши
J-K-L — особенно полезная группа позволяет просматривать материал почти как монтажёр:
J  ← назад
K  ■ стоп
L  → вперёд

### Стабилизация конкретного клипа
**Стабилизация** (фильтр Стабилизировать) — только для тех клипов/фрагментов, где она действительно нужна.
Стабилизация изменяет геометрию кадра: компенсирует дрожание, может увеличивать изображение и обрезать края.
лучше выполнить **до окончательной обработки изображения**.
* Если вы собираетесь стабилизировать отдельные фрагменты, не объединяйте их обратно после нарезки.

### Если при стабилизации резкий скачок кадра на 50–90°
Похоже на ошибочную компенсацию поворота или слишком большой поворот для обычного устранения дрожания.
Начните с проверки:
1. Отключите «Стабилизацию» и проиграйте это место.
2. Если скачок исчез — включите фильтр и выполните «Анализ» заново, сохранив результат в новый .stab именно для этого клипа. Не выбирайте файл анализа другой сцены.
3. Дождитесь завершения задания и проверьте тот же момент.
Если скачок повторяется точно в том же месте, посмотрите исходник: нет ли там резкого рывка, смазанного кадра или человека, закрывающего фон. Такой короткий участок лучше оставить без стабилизации, чем исправлять ошибочный поворот встречным поворотом.

### Фильтры для всей дорожки Timeline
1. **Шумоподавление** (фильтр Уменьшить шум Вейвлет)/ **очистка изображения**.
После стабилизации получаем окончательную геометрию кадра и затем убираем цифровой шум.
Например:
```text
Stabilize
   ↓
Vaguedenoiser
```

* Сильное шумоподавление применять осторожно: оно может уничтожить мелкие детали.
* Если шум не был убран сначала, Sharpen может подчёркивать шум.
2. **Цветокоррекция** (фильтры Баланс белого, Контраст, Сортировка по цвету)
После очистки изображения удобно заниматься:
- экспозицией;
- контрастом;
- балансом белого;
- насыщенностью;
* Если под вашим Colgate имеется в виду используемый вами фильтр цветокоррекции, я бы оставил его после Contrast.
3. **Резкость** (фмльтр Повысить резкость) — если необходима.
* Резкость лучше ставить после шумоподавления и цветокоррекции.
* Если сначала увеличить резкость, а потом применить шумоподавление, часть созданной резкости всё равно будет уничтожена.

### Проверить переходы
Наложение клипов на одной дорожке является стандартным способом создания переходов в Shotcut
1. Разместите два клипа рядом на V1.
2. Перетащите второй клип немного влево, поверх конца первого.
3. В месте перекрытия появится фиолетовый блок перехода.
4. Выделите этот блок.
5. Откройте панель Свойства.
6. В поле Видео выберите тип перехода:
- Dissolve — обычное растворение;
- Bar, Iris, Clock, Diagonal и другие фигурные переходы.
7. Длительность регулируется растягиванием краёв фиолетового блока.

### Проверить звук
В MediaPanel pipeline очищает звук и собирает клипы для редактирования в Shotcut с очищенным звуком.

### Проверить титры

### Проверить общую длительность
Для размещения на Youtube рекомендуемая длительность видно 10 - 15 минут.

## Как установить пресет набора фильтров в Shotcut

### В MediaPanel
1. Выполните меню `MediaPanel UI`
```text
1) System status -> 5) Import Shotcut filter sets
```

2. Откройте в `Shotcut`
```text
Фильтры → + → Наборы / Sets
```

Там должен появиться, например:
```bash
Oppo_Reno_11F_Concert
```

3. Применяйте Набор фильтров для всей дорожки

### В Shotcut
У вас `Shotcut Flatpak`, поэтому лучше не угадывать путь вручную.

1. Откройте `Shotcut`.
2. Выберите:
```tetx
Настройки → Каталог данных приложения → Показать
```

3. Найдите каталог:
```bash
filter-sets
```

* Если каталога нет — создайте именно с таким названием

4. Скопируйте туда к примеру файл:
```bash
Oppo_Reno_11F_Concert
```

5. Полностью закройте `Shotcut`.
6. Запустите `Shotcut` снова.
7. Откройте 
```text
Фильтры → + → Наборы
```
Там должен появиться: `Oppo_Reno_11F_Concert`

## Тонкая настройка пресетов

Коллекции пресетов очень удобны при обработке видео. Однако отдельные фрагменты видео могут потребовать **тонкой настройки**.
В процессе тонкой настройки вы изменяете параметр фильтра на один-два шага и просматриваете результат.
1. На вкладке проекта в окне проигрывателя выберите **Toggle Zoom** (Переключить масштаб), чтобы оценить эффект от изменения параметра фильтра при сильном увеличении.
2. Выберите **Player > External Monitor > Preview Window (HDR)** (или нажмите **Ctrl+`**), чтобы увидеть результат изменений в видео.

## Исправление дефектов в новостях и спорте при монтаже в MediaPanel

### Перекрытие дефектного места перебивкой
Звук продолжается непрерывно, а плохой кадр заменяется другим видеопланом.
1. Не редактируйте повторно 001_Video_final.mp4, повторное кодирование немного снизит качество. 
Сделайте копию оригинального .mlt проекта
```bash
001_Video (Копия).mlt
```
2. Откройте Shotcut и сохраните копию .mlt для ремонта, например Сохранить как:
```bash
001_Video_repair.mlt
```

3. Отделите звук от проблемного клипа командой Detach Audio и оставьте его непрерывным на аудиодорожке A1. Shotcut поддерживает отделение звука через контекстное меню клипа.
4. Заблокируйте A1, чтобы случайно не сдвинуть звук.
5. На видеодорожке сделайте разрез:
- за несколько кадров до появления дефекта;
- сразу после её исчезновения.
6. Удалите только дефектную часть видео через Lift/Поднять, оставив промежуток в клипе. Не используйте Ripple Delete, иначе всё справа сдвинется относительно звука.
7. На V2 положите перебивку точно над образовавшимся промежутком.
8. Сохраните .mlt как основной для последующего экспорта:
```bash
001_Video.mlt
```

* У вас получится три ,mlt, один основной для экспорта и два для возможных изменений в будущем.
Лучше взять не непосредственно предыдущую секунду, а похожий чистый фрагмент из другого места выступления:
- общий план сцены;
- музыканта или барабанщика;
- движение света;
- руки исполнителя или инструмент;
- реакцию зрителей.
Или можно использовать нарезку из каталога scenes/ проекта, созданную pipeline.
Если повторить непосредственно соседние кадры, зритель может заметить скачок назад. Если другого плана нет, повтор можно замаскировать небольшим увеличением до 103–105%.

### Замедление
Для секундного промежутка возьмите около 0,7–0,85 секунды чистого материала и установите скорость:
```bash
0,70–0,85×
```

Формула:
```text
Скорость = длительность исходной перебивки / длительность промежутка
```

Например:
```text
0,75 секунды / 1,00 секунды = скорость 0,75×
```

* Если исходник снят в 60 fps, а проект около 30 fps, можно использовать 0,5× — движение останется плавным. Для исходника 30 fps лучше не опускаться ниже 0,75–0,8×, иначе может появиться подёргивание.

На входе и выходе попробуйте:
- жёсткую склейку точно по удару музыки — часто выглядит лучше всего;
- либо очень короткое растворение на 3–5 кадров, если планы сильно различаются.

[!] Главное: звук не разрезать и не замедлять. Тогда музыка и атмосфера фестиваля останутся естественными, а секундная перебивка будет восприниматься как намеренный режиссёрский монтаж.

## Создание короткого (short) видео

1. Откройте `Shotcut` в `MediaPanel UI`
```text
6) Tools -> 1) Video tools -> 1) Shotcut
```

2. Создайте `Новый проект`
Папка проектов: 001_Текущий_проект
Название проекта: short
Видеорежим: 4K UHD 2160p и частота кадров по частоте кадров выбранного scene
Нажмите: Начало
3. Выберите файл из каталога `scenes/`
```text
Файл -> Открыть файл
```

4. Перетащите файл на Шкалу времени
5. Если нужно повторите пункты 3. и 4.
6. Можно сделать всю нужную обработку клипов: нарезка, если нужно стабилизация, цветокоррекция, субтитры
7. Из горизонтального видео можно сделать в `Shotcut` вертикальное только для элемента `Вывод` `Шкалы Времени`
```text
Timeline -> Вывод -> Экспорт -> Расширенный -> Переделать рамку
```
Убедитесь, что разрешение 1080×1920 или больше, частота кадров соответствует исходному, H.264 NVENC, качество CQ 18–20, звук AAC 192–256 Кбит/с
* `Переделать рамку` уменьшает разрешение, экспортируйте из 4К видео с частотой кадров исходного файла.
8. Сохраните законченный проект в каталоге `short/` с именем "001_Video_short.mlt"
```text
Файл -> Сохранить как..
```

9. Экспортируйте созданное короткое видео в каталог `short/`
```text
Файл-> Экпорт -> Видео/Аудио -> 001_Video_short.mp4
```
